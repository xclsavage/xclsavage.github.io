Private Fantasy Football Application

🏈 The Dirty Dozen Fantasy Recap

A private fantasy football analytics and weekly recap tool built for The Dirty Dozen, a 12-team Yahoo Fantasy Football league.

What it does

The application analyzes Yahoo Fantasy Sports league data to generate weekly matchup recaps, statistical highlights, power rankings, weekly awards, and other league statistics for league members.

Intended Use

This application is intended solely for private use by one fantasy football league and its members. It is not a public fantasy platform and is not intended for distribution across multiple leagues.

Yahoo Fantasy Data

The application is designed to use read-only Yahoo Fantasy Sports data for statistical analysis and recap generation. It does not modify league settings or conduct fantasy transactions.
